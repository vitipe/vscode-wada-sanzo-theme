# Wada Sanzō Color Themes para VS Code 🎨

Colección de temas oscuros refinados y de alta legibilidad inspirados en el catálogo de combinaciones de color de **Wada Sanzō** (*Haishoku Sōkan* / *A Dictionary of Color Combinations*, 1930s).

Diseñados para programar sin fatiga visual: **ningún tema usa fondos negros `#000000` agresivos**, asegurando un contraste certificado **WCAG AAA/AA** con máxima diferenciación cromática entre tokens de sintaxis.

---

## Las 4 Armonías Principales

### 1. Wada Sanzō - Clásica (*Shu-iro & Yamabuki*)
* **Fondo:** `#222428` *(Warm Charcoal)*
* **Atmósfera:** El contraste arquetípico de los grabados Shōwa.
* **Sintaxis:**
  * Keywords: `#E86452` (*Rojo Laca Shu-iro*)
  * Funciones: `#EDB83F` (*Oro Cálido Yamabuki*)
  * Strings: `#7EBF77` (*Verde Bambú Take-iro*)
  * Tipos: `#5EB5D6` (*Azul Lapislázuli Ruri*)
  * Números: `#FA9E5E` (*Mandarina Daidai*)
  * Operadores: `#C78FE6` (*Violeta Iris Kikyō*)

### 2. Wada Sanzō - Aizome (*Índigo & Luna*)
* **Fondo:** `#1E222B` *(Noche Índigo Japonesa)*
* **Atmósfera:** Noche de tinta azulada con metales y pigmentos acuáticos.
* **Sintaxis:**
  * Keywords: `#F06558` (*Carmesí Cinabrio Shinsha*)
  * Funciones: `#F5C854` (*Oro Lunar Tsuki-kin*)
  * Strings: `#88D49E` (*Sauce Marino Yanagi*)
  * Tipos: `#4ECDC4` (*Turquesa Martín Pescador Kawasemi*)
  * Números: `#FF8C7A` (*Salmón Coral Sango*)
  * Operadores: `#CF94EE` (*Lavanda Sumire*)

### 3. Wada Sanzō - Momiji (*Otoño & Madera*)
* **Fondo:** `#262322` *(Carbón Tostado & Madera)*
* **Atmósfera:** Bosques de Kioto en otoño y calidez de té tostado (*hōjicha*).
* **Sintaxis:**
  * Keywords: `#EB5D50` (*Rojo Arce Momiji*)
  * Funciones: `#F2B833` (*Amarillo Hojas de Ginkgo Ichō*)
  * Strings: `#8FC975` (*Verde Aguja de Cedro Sugi*)
  * Tipos: `#54BFBA` (*Esmalte Cerámico Seiji-ruri*)
  * Números: `#F28D52` (*Caqui Seco Hoshigaki*)
  * Operadores: `#D98ACB` (*Flor de Ciruelo Ume*)

### 4. Wada Sanzō - Komorebi (*Té Verde & Bosque*)
* **Fondo:** `#212523` *(Carbón Musgo Botánico)*
* **Atmósfera:** Luz filtrada a través de las hojas y frescura vegetal.
* **Sintaxis:**
  * Keywords: `#E25D4A` (*Terracota Vivo Hiwadabuki*)
  * Funciones: `#EAC645` (*Limón Ocre Kihada*)
  * Strings: `#55C595` (*Verde Jade Wasabi Hisui*)
  * Tipos: `#6CB5E8` (*Azul Hortensia Ajisai*)
  * Números: `#FA946B` (*Melón Coral Toki*)
  * Operadores: `#D59CE8` (*Glicinia Suave Fuji*)

*(Además incluye la variante **Sumi Slate** `#24272E` para quienes prefieran un gris pizarra más frío).*

---

## Cómo Cambiar de Tema en VS Code

1. Pulsa **`Cmd + K`** seguido de **`Cmd + T`** (o abre la Paleta con `Cmd + Shift + P` y escribe `Preferences: Color Theme`).
2. Elige cualquiera de las variantes de **Wada Sanzō**.
